Книга в EPUB

Соберите книгу с kanunu8.com по ссылке или загрузите готовый EPUB. При желании книгу можно перевести на русский через OpenRouter.

Ключ хранится только в этом браузере и отправляется только на openrouter.ai.
По умолчанию DeepSeek. Можно указать любую модель OpenRouter, например deepseek/deepseek-v4-pro.
По одному на строку. Помогает переводить имена и термины одинаково во всей книге.

Пока идёт перевод, не закрывайте вкладку. Если процесс прервался, запустите его снова: уже переведённые части сохранены и повторно не оплачиваются.

Для книг в общественном достоянии (классика) или текстов, на которые у вас есть права.
