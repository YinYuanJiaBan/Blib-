# Книга в EPUB: веб-версия

Страница, куда вставляешь ссылку на оглавление книги на kanunu8.com, и она собирает EPUB на языке оригинала. Работает в Safari на iPad.

Сайт kanunu8 не даёт загружать свои страницы с чужих сайтов, поэтому страница работает через маленький бесплатный сервер на **Cloudflare Workers**. Всё помещается в один файл, `worker.js`: он и показывает страницу, и загружает главы.

## Установка (один раз, примерно 5 минут, можно с iPad)
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Откройте **Workers & Pages → Create → Create Worker** (шаблон «Hello World»). Придумайте имя, например `book-epub`, и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите весь код в редакторе и вставьте содержимое файла [`worker.js`](worker.js). Нажмите **Deploy**.
4. Откройте адрес вида `https://book-epub.<ваше-имя>.workers.dev`. Это и есть ваша страница, добавьте её в закладки или на экран «Домой».

## Использование
Вставьте ссылку на оглавление, например `https://www.kanunu8.com/files/old/2011/2560.html`, и нажмите «Собрать EPUB». Когда сборка закончится, нажмите «Скачать»: файл сохранится в «Загрузки», оттуда его можно открыть в «Книгах».

## Перевод на русский (OpenRouter)
1. Поставьте галочку **«Перевести на русский»**, вставьте ключ OpenRouter (`sk-or-v1-…`). Модель по умолчанию `deepseek/deepseek-chat`.
2. Перевести можно двумя способами:
   - **«По ссылке»**: книга загружается с сайта и сразу переводится;
   - **«Готовый EPUB»**: выберите уже скачанный файл, и получите русскую версию.
3. **Глоссарий** (необязательно): строки вида `顾茫 = Гу Ман`. С ним имена переводятся одинаково во всей книге.
4. **«Оставить оригинал»**: над каждым абзацем перевода будет китайский текст.

Как устроено:
- Ключ хранится только в браузере на вашем устройстве и отправляется только на openrouter.ai.
- Переведённые части сохраняются в браузере. Если перевод прервался, запустите его снова: готовое повторно не оплачивается.
- Начните с пробы: «Только первые глав: 2». Так сразу видно качество и цену.

## Для разработчика
- `index.html` — исходник страницы; `worker.template.js` — исходник сервера.
- `python3 build.py` собирает из них `worker.js`. Запускайте после правок.
- Сервер загружает страницы только с kanunu8.com, поэтому чужим открытым прокси он не станет.
- Бесплатного тарифа Cloudflare (100 000 запросов в день) хватит на сотни книг.

> Для книг в общественном достоянии (классика) или текстов, на которые у вас есть права.
