# Переводчик сайтов: китайский → русский

Расширение для Chrome / Edge / Яндекс.Браузера (Manifest V3). Переводит китайские веб-страницы на русский прямо на месте и сохраняет вёрстку.

## Возможности
- Перевод всего текста страницы, заголовка вкладки и подсказок (`title`, `placeholder`, `alt`, `aria-label`, текст кнопок).
- Переводит и контент, который подгружается позже (ленты, бесконечная прокрутка, SPA).
- Кнопка «Показать оригинал» возвращает исходный текст.
- Автоперевод китайских сайтов (по желанию) и список сайтов, которые не нужно переводить.
- Горячая клавиша **Alt+T**: перевести или вернуть оригинал. Пункты в контекстном меню.
- Не трогает `<code>`, `<script>`, поля ввода и элементы с `translate="no"`.
- Переводы кэшируются, запросы отправляются пакетами.

## Установка
1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте `chrome://extensions` (в Edge: `edge://extensions`).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.

## Использование
Откройте китайский сайт, нажмите на значок расширения и выберите «Перевести страницу» (или нажмите Alt+T).

## Как это работает
Контент-скрипт (`content.js`) находит текстовые узлы с иероглифами и отправляет их пакетами в фоновый скрипт (`background.js`). Тот запрашивает перевод у публичного эндпоинта Google Translate (`translate.googleapis.com`, ключ API не нужен) и возвращает результат, который подставляется на место исходного текста.

Тексты страниц уходят на сервис Google. Не включайте автоперевод на сайтах с конфиденциальными данными.
