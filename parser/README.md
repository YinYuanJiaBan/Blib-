# book2epub — книга с kanunu8.com → EPUB (с переводом на русский)

Скрипт скачивает книгу с сайта 努努书坊 (kanunu8.com) по ссылке на оглавление и собирает EPUB. При желании сразу переводит её с китайского на русский. Нужен только Python 3.8+, сторонние библиотеки не нужны.

> Используйте для книг в общественном достоянии (классика: 鲁迅, 曹雪芹, 吴敬梓, 老舍…) или для текстов, на которые у вас есть права.

## Запуск
```bash
# Китайский оригинал
python3 book2epub.py https://www.kanunu8.com/files/old/2011/2560.html

# Перевод на русский
python3 book2epub.py URL --translate

# Двуязычная книга: под каждым китайским абзацем перевод
python3 book2epub.py URL --translate --bilingual

# FB2: прочитать .fb2 / .fb2.zip и собрать книгу в FB2
python3 book2epub.py book.fb2 --translate --engine openrouter   # → *.fb2
python3 book2epub.py URL --format fb2

# Проба на первых 3 главах
python3 book2epub.py URL --translate --limit 3 -o proba.epub
```

| Параметр | Что делает |
|---|---|
| `--translate` | перевести на русский (через Google Translate) |
| `--bilingual` | оставить оригинал рядом с переводом (удобно для изучения языка) |
| `--lang en` | перевести на другой язык |
| `--limit N` | только первые N глав |
| `--title "Остатки грязи"` | своё название книги вместо предложенного нейросетью (попадёт в справку и в глоссарий перевода) |
| `--cover обложка.jpg` | обложка книги (JPG, PNG, GIF или WebP); у EPUB и FB2 на входе своя обложка сохраняется и без этого |
| `-o файл.epub` | имя выходного файла (`.fb2` — собрать FB2) |
| `--format fb2` | формат книги: `epub` или `fb2` (по умолчанию как у `-o` или у входного файла) |
| `--max-chars N` | книга длиннее N знаков китайского текста делится на тома (по умолчанию 140000, `0` — не делить) |
| `--workers`, `--delay` | скорость загрузки (по умолчанию 4 потока и пауза 0,3 с) |

Длинная книга (больше 140 000 знаков китайского текста, без пробелов) собирается в несколько файлов: `книга_1.epub`, `книга_2.epub`… Деление идёт по границам глав, тома выходят примерно равными, и ни один не превышает лимита. Глава длиннее лимита режется по абзацам. Для переведённой книги считается китайский оригинал, а не перевод.

Загруженные главы и переводы сохраняются в `.book2epub_cache`. Если процесс прервался, просто запустите команду снова, и он продолжит с того же места.

## На iPad
Подойдёт приложение **a-Shell** (бесплатное, App Store): скопируйте туда `book2epub.py` и выполните ту же команду. Готовый EPUB откроется в «Книгах».

## Ограничения
- Машинный перевод классического китайского языка получается дословным и местами корявым. Имена и реалии иногда переводятся буквально.
- Если сайт поменяет вёрстку, разбор глав может перестать работать.
