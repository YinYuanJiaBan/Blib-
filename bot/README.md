# Telegram-бот «Книга в EPUB»

Присылаете боту ссылку на оглавление книги с kanunu8.com или файл `.epub` и выбираете кнопку:
- **📖 Оригинал** — EPUB на китайском;
- **🇷🇺 Перевод** — EPUB на русском (DeepSeek через OpenRouter);
- **🔀 Китайский + русский** — оригинал над каждым абзацем перевода.

Готовый файл приходит в чат. Пока книга собирается, бот показывает прогресс.

## Справка о книге
С каждой книгой, до начала перевода, бот присылает справку:
- русское название (устоявшееся, если оно есть), дословный перевод, английское название, автор, жанр;
- о чём книга, в 3–6 предложениях;
- персонажи: иероглифы, пиньинь, имя по Палладию, пол и роль;
- места и термины: государства, титулы, секты.

Справку составляет та же модель по первым трём главам и по своим знаниям, если узнаёт книгу. Имена из справки становятся глоссарием перевода, поэтому во всей книге они пишутся одинаково. Пол персонажей помогает модели правильно согласовать глаголы. Глоссарий из сообщения важнее справки: строка `顾茫 = Гу Ман` заменит имя и в справке, и в переводе.

Справка попадает и в сам EPUB, на страницу «О книге» после титула. Для режима «Оригинал» справка тоже приходит, если задан ключ OpenRouter.

## Сноски к идиомам и метафорам
Переводчик сам находит чэнъюи (成语), устойчивые метафоры, аллюзии на историю и литературу, игру слов и культурные реалии. В тексте выражение переведено художественно, а рядом стоит номер сноски. В Apple Books и большинстве читалок сноска открывается нажатием на номер, а в конце главы собраны все сноски этой главы:

> **金枝玉叶 (jīn zhī yù yè).** Дословно: «золотая ветвь, нефритовые листья». Древнее выражение о человеке высокого происхождения, драгоценном и благородном, которого нельзя равнять с простыми людьми.

Одно и то же выражение поясняется только при первом появлении в книге. Чтобы перевести без сносок, добавьте к ссылке (или к подписи EPUB-файла) слова «без сносок».

## Правила перевода
Модель получает подробную инструкцию: ничего не добавлять и не пропускать, сохранять образы и их порядок, выбирать значение многозначных слов по контексту, не заменять реалии эпохи современными (кисть и тушь, а не перо и чернила) и оформлять диалоги по-русски, через тире. Каждый пакет абзацев отправляется вместе с тремя предыдущими абзацами для контекста, чтобы не терялись род и смысл на стыках.

В том же сообщении можно добавить:
```
https://www.kanunu8.com/files/old/2011/2560.html
3
王冕 = Ван Мянь
```
Здесь `3` означает «только первые 3 главы» (удобно для пробы), а строки с `=` задают глоссарий имён.

## Как это устроено
```
Telegram → Cloudflare Worker (bot/worker.js) → GitHub Actions (bot/job.py) → EPUB в Telegram
```
Воркер только принимает сообщения и запускает задачу. Книгу скачивает и переводит GitHub Actions: там нет ограничений по времени, как у Cloudflare. Всё бесплатно, оплачивается только перевод в OpenRouter.

## Настройка (один раз, около 15 минут, можно с iPad)

### 1. Создайте бота
В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя. Сохраните **токен** (вида `123456:AA…`).

### 2. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_BOT_TOKEN` — токен бота;
- `OPENROUTER_API_KEY` — ключ OpenRouter (`sk-or-v1-…`).

Модель можно сменить: на вкладке **Variables** создайте `OPENROUTER_MODEL`, например `deepseek/deepseek-v4-pro`. По умолчанию используется `deepseek/deepseek-chat`.

### 3. Токен GitHub для воркера
GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- Repository access: **Only select repositories → Blib-**;
- Permissions → Repository permissions → **Contents: Read and write**;
- скопируйте токен (`github_pat_…`).

### 4. Воркер в Cloudflare
1. **Workers & Pages → Create → Start with Hello World!**, имя `book-bot`, нажмите **Deploy**.
2. **Edit code**: удалите всё, вставьте содержимое [`bot/worker.js`](worker.js), нажмите **Deploy**.
3. **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота |
| `WEBHOOK_SECRET` | Secret | любая длинная строка из латинских букв и цифр |
| `GH_TOKEN` | Secret | токен GitHub из шага 3 |
| `GH_REPO` | Text | `YinYuanJiaBan/Blib-` |
| `ALLOWED_USERS` | Text | пока `0`, заполните на шаге 6 |

### 5. Подключите бота
Откройте в Safari: `https://book-bot.<ваше-имя>.workers.dev/setup?key=<ваш WEBHOOK_SECRET>`.
Должно быть «Webhook: ✅ установлен» и галочки у всех переменных.

### 6. Разрешите себе доступ
Напишите боту `/id`, и он пришлёт ваш Telegram ID. Впишите его в `ALLOWED_USERS` (несколько ID пишутся через запятую) и нажмите **Deploy**. Посторонние пользователи бота не смогут им пользоваться и тратить ваши деньги.

Готово: отправьте боту ссылку.

## Автообновление воркеров
Воркеры в Cloudflare обновляются сами при каждом изменении кода в GitHub (`.github/workflows/deploy-workers.yml`). Для этого один раз добавьте секреты в **Settings → Secrets and variables → Actions**:
- `CLOUDFLARE_API_TOKEN`: в Cloudflare откройте **My Profile → API Tokens → Create Token**, выберите шаблон **Edit Cloudflare Workers**, затем **Continue to summary → Create Token**;
- `CLOUDFLARE_ACCOUNT_ID`: ID аккаунта, он показан на странице **Workers & Pages** справа (Account ID).

Веб-страница обновляется так же, если на вкладке **Variables** задать `WEB_WORKER_NAME`, то есть имя её воркера.
Переменные и секреты, заданные в панели Cloudflare, при обновлении сохраняются.

## Если что-то не так
- **Бот молчит.** Откройте `/setup?key=…` ещё раз и проверьте галочки.
- **«GitHub не принял задачу».** Проверьте `GH_TOKEN` (права Contents: Read and write на репозиторий Blib-) и `GH_REPO`.
- **Задача запустилась, но упала.** Откройте в репозитории вкладку **Actions** и посмотрите журнал последнего запуска «Книга для Telegram-бота».
- **Перевод прервался.** Нажмите кнопку ещё раз: скачанные главы и переводы сохраняются в кэше Actions, и повторно платить не придётся.

Репозиторий публичный, поэтому список запусков в Actions виден всем. Ссылки на книги, глоссарий и сами тексты в журнал не выводятся.

## Расход и скорость перевода

Переменные репозитория (Settings → Secrets and variables → Actions → Variables), все необязательные:

- `TRANSLATE_BUDGET_USD` — лимит расходов на одну книгу в долларах. Дойдя до него, бот присылает главы,
  переведённые целиком; если прислать книгу ещё раз, перевод продолжится с того же места.
- `OPENROUTER_PROVIDER` — закрепить провайдера OpenRouter (например, `DeepSeek`), если у выбранного
  по умолчанию не работает кэширование промпта.
- `OPENROUTER_REASONING=on` — включить «размышления» модели. По умолчанию они выключены: на переводе
  они в ~12 раз увеличивали число токенов и почти в 10 раз время, а заметной пользы не давали
  (разве что сносок становится больше).

Кэш хранит перевод каждого абзаца отдельно, так что прерванный перевод не пропадает, а смена размера
пакетов его не сбрасывает. В конце бот пишет в подписи к файлу, сколько токенов и денег ушло.
