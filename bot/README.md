# Telegram-бот «Книга в EPUB / FB2»

Присылаете боту ссылку на оглавление книги с kanunu8.com или файл `.epub` / `.fb2` / `.fb2.zip` и выбираете кнопку:
- **📖 Оригинал** — EPUB на китайском;
- **🇷🇺 Перевод** — EPUB на русском (DeepSeek через OpenRouter);
- **🔀 Китайский + русский** — оригинал над каждым абзацем перевода.

Готовый файл приходит в чат. Книга возвращается в том же формате, в каком пришла: FB2 → FB2, EPUB → EPUB, по ссылке — EPUB. Чтобы получить другой формат, допишите к ссылке или в подпись к файлу `fb2` или `epub`. Пока книга собирается, бот показывает прогресс.

Книга длиннее 140 000 знаков китайского текста приходит несколькими файлами («Книга 1 из 3» и т. д.), поделёнными по главам. Лимит меняется переменной репозитория `MAX_PART_CHARS` (Settings → Secrets and variables → Actions → Variables) (`0` — не делить). Из библиотеки такая книга тоже выдаётся всеми томами.

## Библиотека готовых книг
Каждая собранная книга сохраняется. Если снова прислать ту же ссылку (или тот же EPUB) и нажать ту же кнопку, бот сразу пришлёт готовый файл. Перевод не запускается и денег не тратит.
- **Поиск по названию.** Просто напишите боту название, ссылка не нужна: «Неофициальная история конфуцианцев», «儒林外史», «The Scholars», «rulin waishi» или имя автора. Подойдёт и часть названия, регистр, буква «ё» и тоны пиньиня не важны. Если нашлась одна книга, бот сразу пришлёт файл; если несколько (например, перевод и двуязычная версия), предложит выбрать.
- **/library** — список всех сохранённых книг; нажмите на книгу, чтобы получить файл. `/library слово` — то же, что поиск.
- **✏️ Изменить** под файлом (в мини-приложении — «✏️ Название и обложка») — поменять название или обложку готовой книги, см. ниже.
- **🔄 Собрать заново** под файлом из библиотеки — перевести книгу ещё раз с теми же ссылкой и настройками (например, после правок в боте); новый файл заменит старый.
- **🗑 Убрать из библиотеки** — забыть файл.

### Мини-приложение «Библиотека»
Кнопка **Библиотека** слева от поля ввода (или «📚 Открыть библиотеку с обложками» в `/library`) открывает внутри Telegram полку с карточками книг:
- обложки, название, автор, значок режима (🇷🇺 перевод, 🔀 двуязычная, 📖 оригинал, 📗 загруженная);
- поиск по любому варианту названия и автору, фильтры по режиму, сортировка по дате или по алфавиту;
- карточка книги: оригинальное название, автор, жанр, о чём книга, другие названия; кнопки **Прислать в чат**, **Собрать заново**, **Убрать из библиотеки**.

**Обложки.** Берутся из самого файла: у EPUB — обложка по стандарту EPUB 3 или EPUB 2, картинка со словом cover в имени или страница обложки; у FB2 — картинка из `<coverpage>`. У книг, сохранённых раньше, обложка достаётся при первом открытии библиотеки и запоминается в KV. Если обложки в файле нет (например, у книг с kanunu8), рисуется своя: «сшитая» китайская книга с наклейкой-названием иероглифами. Если переводимый EPUB или FB2 был с обложкой, она переходит и в переведённый файл.

Жанр и описание показываются у книг, переведённых после этого обновления: бот сохраняет их из справки о книге. Для загруженных EPUB они берутся из метаданных файла, если там есть.

Приложение открывается только у пользователей из `ALLOWED_USERS`: воркер проверяет подпись Telegram. Кнопка появляется после `/start` или `/library` (или после повторного открытия `/setup`), в @BotFather ничего настраивать не нужно.

### Загрузка готовых EPUB и FB2
Уже готовую книгу (свою или переведённую где-то ещё) можно положить в библиотеку без перевода:
- пришлите файл `.epub` и нажмите **📥 Сохранить в библиотеку**; или подпишите файл словами «в библиотеку»;
- чтобы загрузить много книг сразу, отправьте **/upload**: на 3 часа каждый присланный EPUB или FB2 сохраняется сам, без вопросов. Ещё раз `/upload` выключает этот режим.

Сначала название и автор берутся из метаданных EPUB (или из имени файла). Но метаданные часто испорчены: транслит вроде `Dolgaya_igra`, автор вместе с переводчиком через подчёркивание. Поэтому сразу после загрузки бот отдаёт начало книги модели (та же, что для перевода, через OpenRouter; стоит доли цента), и она определяет настоящее название, автора, оригинальное название, серию, жанр и пишет, о чём книга. Через минуту сообщение о загрузке дополняется строкой «📝 «Долгая игра», Рейчел Рид — описание добавлено», а карточка в библиотеке обновляется. Старые варианты названия остаются для поиска. Для книг, загруженных раньше, в карточке мини-приложения есть кнопка **📝 Составить описание**. По ним книга потом ищется так же, как переведённые. Файлы больше 20 МБ перевести нельзя (Telegram не даёт боту их скачать), но сохранить в библиотеку можно: тогда название берётся из имени файла. Тот же самый файл второй раз не сохраняется.

### Сколько книг можно хранить
Файлы лежат на серверах Telegram, общего лимита на их число у бота нет, и место за них не платится. Ограничения такие:
- размер одного файла: присланный пользователем — до 2 ГБ (до 4 ГБ с Premium), собранный ботом — до 50 МБ;
- записи в Cloudflare KV на бесплатном тарифе: 1 ГБ места (запись о книге весит около 1–2 КБ, то есть сотни тысяч книг) и 1000 записей в день, то есть не больше ~1000 загрузок в сутки;
- `/library` и поиск просматривают первые 1000 книг, а в списке показывают 50 последних.

Ссылка на файл (`file_id`) действует только для этого бота. Если создать нового бота с другим токеном, старые записи перестанут открываться. Держите копии важных книг у себя.

Книга считается той же, если совпадают ссылка (или файл), режим, число глав, глоссарий и «без сносок». С другим глоссарием будет новый перевод. Книга, в которой не загрузились главы или остались непереведённые фрагменты, не сохраняется: повторный запрос её допереведёт.

Сами файлы хранит Telegram, а в Cloudflare KV (`book-bot-library`) лежит только запись: все варианты названия из справки о книге (русское, дословное, английское, пиньинь, оригинал), автор, ссылка на файл и настройки сборки. Хранилище создаётся само при автообновлении воркера (см. ниже). Если воркер обновляется вручную, создайте в Cloudflare **Storage & Databases → KV** хранилище и подключите его к воркеру: **Settings → Bindings → Add → KV namespace**, имя переменной `BOOKS`.

## Своё название и обложка
Прислав ссылку или EPUB, бот сначала спросит: **«✏️ Хотите внести изменения — поменять название или обложку?»**
- **Нет, дальше** — обычный выбор: оригинал, перевод, двуязычная книга или «Сохранить в библиотеку».
- **✏️ Да, изменить** — откроется меню:
  - **📝 Название** — бот попросит написать название ответом на его сообщение. Например, нейросеть перевела «Остатки скверны», а в России книгу знают как «Остатки грязи»: пишете «Остатки грязи». Название будет в справке о книге (с пометкой, что нейросеть предлагала), в её глоссарии (`剩余的污秽 = Остатки грязи`) — переводчик пишет его так же и внутри текста, — на титульной странице, в метаданных EPUB, в имени файла и в библиотеке. Поиск находит книгу по обоим названиям. Ответ «-» вернёт название от нейросети.
  - **🖼 Обложка** — пришлите картинку ответом на сообщение бота: фото или файл JPG/PNG. У книги с kanunu8 обложки нет, так её можно добавить.
  - **✅ Готово** — к выбору режима.

Обложка вшивается в EPUB или FB2: её видят «Книги» и ридеры, она становится значком файла в Telegram и показывается в мини-приложении «Библиотека» (оно берёт обложку из самого файла).

Быстрый способ без меню: пришлите картинку с подписью — ссылкой на книгу, картинка станет обложкой. Название можно задать и строкой глоссария с китайским названием: `剩余的污秽 = Остатки грязи`.

**✏️ Изменить** у готовой книги открывает то же меню. Перевод при этом берётся из кэша и заново не оплачивается, если кэш в Actions ещё жив (он удаляется через 7 дней без использования); новый файл заменит старый в библиотеке. Если книга уже есть в библиотеке, а вы присылаете её с изменениями, бот не отдаёт старый файл, а собирает заново.

Меню изменений хранится в KV-хранилище библиотеки; без него бот сразу предлагает выбор режима.

## Справка о книге
С каждой книгой, до начала перевода, бот присылает справку:
- русское название (устоявшееся, если оно есть), дословный перевод, английское название, автор, жанр;
- о чём книга, в 3–6 предложениях;
- персонажи: иероглифы, пиньинь, имя по Палладию, пол и роль;
- места и термины: государства, титулы, секты.

Справку составляет та же модель по первым трём главам и по своим знаниям, если узнаёт книгу. Имена из справки становятся глоссарием перевода, поэтому во всей книге они пишутся одинаково. Пол персонажей помогает модели правильно согласовать глаголы. Глоссарий из сообщения важнее справки: строка `顾茫 = Гу Ман` заменит имя и в справке, и в переводе.

Справка попадает и в саму книгу (EPUB или FB2), на страницу «О книге» после титула. Для режима «Оригинал» справка тоже приходит, если задан ключ OpenRouter.

## Сноски к идиомам и метафорам
Переводчик сам находит чэнъюи (成语), устойчивые метафоры, аллюзии на историю и литературу, игру слов и культурные реалии. В тексте выражение переведено художественно, а рядом стоит номер сноски. В Apple Books и большинстве читалок сноска открывается нажатием на номер, а в конце главы собраны все сноски этой главы:

> **金枝玉叶 (jīn zhī yù yè).** Дословно: «золотая ветвь, нефритовые листья». Древнее выражение о человеке высокого происхождения, драгоценном и благородном, которого нельзя равнять с простыми людьми.

Одно и то же выражение поясняется только при первом появлении в книге. Чтобы перевести без сносок, добавьте к ссылке (или к подписи файла) слова «без сносок».

## Правила перевода
Модель получает подробную инструкцию: ничего не добавлять и не пропускать, сохранять образы и их порядок, выбирать значение многозначных слов по контексту, не заменять реалии эпохи современными (кисть и тушь, а не перо и чернила) и оформлять диалоги по-русски, через тире. Каждый пакет абзацев отправляется вместе с тремя предыдущими абзацами для контекста, чтобы не терялись род и смысл на стыках.

В том же сообщении можно добавить:
```
https://www.kanunu8.com/files/old/2011/2560.html
3
王冕 = Ван Мянь
```
Здесь `3` означает «только первые 3 главы» (удобно для пробы), а строки с `=` задают глоссарий имён.

## Как это устроено
```
Telegram → Cloudflare Worker (bot/worker.js) → GitHub Actions (bot/job.py) → EPUB / FB2 в Telegram
```
Воркер только принимает сообщения и запускает задачу. Книгу скачивает и переводит GitHub Actions: там нет ограничений по времени, как у Cloudflare. Всё бесплатно, оплачивается только перевод в OpenRouter.

## Настройка (один раз, около 15 минут, можно с iPad)

### 1. Создайте бота
В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя. Сохраните **токен** (вида `123456:AA…`).

### 2. Секреты в GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_BOT_TOKEN` — токен бота;
- `OPENROUTER_API_KEY` — ключ OpenRouter (`sk-or-v1-…`).

Модель можно сменить: на вкладке **Variables** создайте `OPENROUTER_MODEL`, например `deepseek/deepseek-v4-pro`. По умолчанию используется `deepseek/deepseek-chat`.

### 3. Токен GitHub для воркера
GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- Repository access: **Only select repositories → Blib-**;
- Permissions → Repository permissions → **Contents: Read and write**;
- скопируйте токен (`github_pat_…`).

### 4. Воркер в Cloudflare
1. **Workers & Pages → Create → Start with Hello World!**, имя `book-bot`, нажмите **Deploy**.
2. **Edit code**: удалите всё, вставьте содержимое [`bot/worker.js`](worker.js), нажмите **Deploy**.
3. **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен бота |
| `WEBHOOK_SECRET` | Secret | любая длинная строка из латинских букв и цифр |
| `GH_TOKEN` | Secret | токен GitHub из шага 3 |
| `GH_REPO` | Text | `YinYuanJiaBan/Blib-` |
| `ALLOWED_USERS` | Text | пока `0`, заполните на шаге 6 |

### 5. Подключите бота
Откройте в Safari: `https://book-bot.<ваше-имя>.workers.dev/setup?key=<ваш WEBHOOK_SECRET>`.
Должно быть «Webhook: ✅ установлен» и галочки у всех переменных.

### 6. Разрешите себе доступ
Напишите боту `/id`, и он пришлёт ваш Telegram ID. Впишите его в `ALLOWED_USERS` (несколько ID пишутся через запятую) и нажмите **Deploy**. Посторонние пользователи бота не смогут им пользоваться и тратить ваши деньги.

Готово: отправьте боту ссылку.

## Автообновление воркеров
Воркеры в Cloudflare обновляются сами при каждом изменении кода в ветке `master` (`.github/workflows/deploy-workers.yml`); изменения в других ветках бота не трогают, пока их не сольют в `master`. Для этого один раз добавьте секреты в **Settings → Secrets and variables → Actions**:
- `CLOUDFLARE_API_TOKEN`: в Cloudflare откройте **My Profile → API Tokens → Create Token**, выберите шаблон **Edit Cloudflare Workers**, затем **Continue to summary → Create Token**;
- `CLOUDFLARE_ACCOUNT_ID`: ID аккаунта, он показан на странице **Workers & Pages** справа (Account ID).

Веб-страница обновляется так же, если на вкладке **Variables** задать `WEB_WORKER_NAME`, то есть имя её воркера.
Переменные и секреты, заданные в панели Cloudflare, при обновлении сохраняются.
При первом обновлении создаётся KV-хранилище `book-bot-library` для библиотеки книг (токен по шаблону «Edit Cloudflare Workers» даёт на это право).

## Если что-то не так
- **Бот молчит.** Откройте `/setup?key=…` ещё раз и проверьте галочки.
- **«GitHub не принял задачу».** Проверьте `GH_TOKEN` (права Contents: Read and write на репозиторий Blib-) и `GH_REPO`.
- **Задача запустилась, но упала.** Откройте в репозитории вкладку **Actions** и посмотрите журнал последнего запуска «Книга для Telegram-бота».
- **Перевод прервался.** Нажмите кнопку ещё раз: скачанные главы и переводы сохраняются в кэше Actions, и повторно платить не придётся.

Репозиторий публичный, поэтому список запусков в Actions виден всем. Ссылки на книги, глоссарий и сами тексты в журнал не выводятся.

## Расход и скорость перевода

Переменные репозитория (Settings → Secrets and variables → Actions → Variables), все необязательные:

- `TRANSLATE_BUDGET_USD` — лимит расходов на одну книгу в долларах. Дойдя до него, бот присылает главы,
  переведённые целиком; если прислать книгу ещё раз, перевод продолжится с того же места.
- `OPENROUTER_PROVIDER` — закрепить провайдера OpenRouter (например, `DeepSeek`), если у выбранного
  по умолчанию не работает кэширование промпта.
- `OPENROUTER_REASONING=on` — включить «размышления» модели. По умолчанию они выключены: на переводе
  они в ~12 раз увеличивали число токенов и почти в 10 раз время, а заметной пользы не давали
  (разве что сносок становится больше).

Кэш хранит перевод каждого абзаца отдельно, так что прерванный перевод не пропадает, а смена размера
пакетов его не сбрасывает. В конце бот пишет в подписи к файлу, сколько токенов и денег ушло.
